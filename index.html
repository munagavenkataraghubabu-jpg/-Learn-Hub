Frontend Architecture Lab

Tailwind CSS vs Bootstrap 5 Framework Lab

Experience how LearnHub contrasts component-first frameworks with utility-first systems. Compare live code representations side by side.

B

Bootstrap 5 Architecture

Component-First

Uses prebuilt semantic component classes like .card, .btn, .navbar, and .row.

col-12 col-md-6
Bootstrap Card Component

Constructed using the official 12-column grid and utility padding.

<div class="card shadow-sm">
  <div class="card-body">
    <h5 class="card-title">Card</h5>
    <button class="btn btn-primary">Go</button>
  </div>
</div>
T

Tailwind CSS Architecture

Utility-First

Uses single-purpose atomic classes like bg-white, p-6, rounded-xl, and shadow-md.

sm:grid md:flex
Tailwind Utility Card

Composed entirely without writing custom CSS selectors.

<div class="bg-white p-4 rounded-xl shadow-md">
  <h5 class="font-bold text-slate-900">Card</h5>
  <button class="bg-slate-900 text-white px-3 py-1.5 rounded">Go</button>
</div>
